# FOOTBALL SPOTLIGHT

Site vitrine responsive indépendant, prêt pour GitHub Pages.

## Fichiers
- `index.html` : structure des pages et sections
- `style.css` : design responsive
- `script.js` : affichage des matchs, actualités et compétitions de démonstration
- `data/competitions.json` : exemple de données de compétitions

## Déploiement sur GitHub
1. Créez un **nouveau dépôt** GitHub (ne remplacez pas votre ancien dépôt).
2. Téléversez le contenu de ce dossier à la racine du nouveau dépôt.
3. Ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez `main` et `/ (root)`, puis enregistrez.

## Important : données réelles
Les matchs, scores et articles de cette première version sont des données de démonstration. Le site ne prétend pas fournir des scores en direct. Pour ajouter des données réelles (scores, classements, statistiques et actualités), il faudra choisir un fournisseur d'API football, vérifier ses compétitions couvertes et ses conditions d'utilisation, puis connecter son API. Ne placez jamais une clé API privée dans `script.js` ou dans un dépôt public.
